## 1. 한 줄 컨셉 (초안)

하나의 신앙으로 뭉친 최대 9인이 고정 클래스로 역할을 나눠, 이단과 타락과 악마에게 잠식당하는 어두운 세계를 정화하며 살아남는 탑다운 샌드박스 어드벤처.
파괴 가능한 월드에 팀이 직접 세운 제단을 중심으로 파고, 짓고, 키우고, 기도하고, 강해져서 더 깊이 나아간다.
월드마다 새로 채우는 컬렉션이 있어, 친구가 없는 날에도 내 클래스는 자란다.

### 직분과 종족 (● 직분 배치 R15 / ● 종족은 클래스와 무관한 꾸미기 R21 / 목록의 제작 체인 등은 ○ 제안, 라운드 9~10)

3직분 × 3 = 9클래스. 하플링은 제외.

| 근접 (지키는 자) | 마법 (부르는 자) | 유틸 (만드는 자) |
|---|---|---|
| 팔라딘 — 탱커 | 성직자 — 신성, 힐·기도 | 약초사 — 버프·디버프, 채집 |
| 시프 — 근접 딜러 | 마법사 — 원소, 인챈트 | 아처 — 원거리 딜러, 사냥·포획 |
| 광부 — 지형 근접 | 룬마스터 — 룬 대장장이 | 기술자 — 장치, 공학 |

- ● 종족(인간·엘프·드워프)은 캐릭터마다 고르는 꾸미기다. 클래스와 무관하고 능력 차이(종족 패시브)는 없다 (R21. R15의 "종족은 클래스에 고정"을 풀었다. 북극성 v6의 인간 3·엘프 3·드워프 3 짝은 R15 기준 그림이고, 이제는 한 예시다)
- ● 체형은 모두 같다 (2등신, R18). 종족별 키·체형 차이와 R17의 거구 팔라딘 예외는 없앴다 (concept-art-brief §5.6)
- 세계관 연결: 하나의 신앙 아래 세 민족. 이단 = 신앙을 버린 자들 → 타락한 변종 적을 세 종족에서 파생
- 제작 체인: 광부의 광석 → 룬마스터의 장비(룬 슬롯) → 마법사의 원소 인챈트. 룬마스터의 룬 부품 → 기술자의 장치 강화
- 오염 대응 분담: 팔라딘 = 되돌리기(치료), 룬마스터 = 결계로 막기(예방)
- 룬마스터의 출정 전 준비: 모루에서 룬 장전 (성직자의 기도와 같은 리듬)

### 클래스 표식 장비 (● R21)

외형은 자유롭게 꾸미므로 클래스는 표식 장비로만 읽는다. 던전앤파이터에서 직업마다 도트에 작은 포인트가 다르듯, 같은 몸에 클래스마다 늘 보이는 장비 하나를 붙인다.

| 직분 | 클래스 | 표식 장비 | 위치 |
|---|---|---|---|
| 근접 | 팔라딘 | 대형 방패 | 팔 |
| | 시프 | 쌍검 | 허리 |
| | 광부 | 곡괭이 | 등 |
| 마법 | 성직자 | 후광 | 머리 위에 뜸 |
| | 마법사 | 책 | 떠서 따라다님 |
| | 룬마스터 | 룬 | 몸 주위를 위성처럼 돎 |
| 유틸 | 약초사 | 씨앗주머니 | 허리 |
| | 아처 | 활 (비교적 큼) | 등 |
| | 기술자 | 망치 (제작용) | 허리 |

- ○ 표식 장비는 꾸미기로 바꾸거나 숨기지 않고, 모자·망토에 가리지 않게 그린다
- ○ 클래스 색은 옷에서 발밑 표식으로 옮긴다 (옷 색은 꾸미기). 판별은 표식 장비 + 발밑 표식 색 (§10)
- ○ 기능이 있던 모자(R17 시트의 광부 램프 투구)는 꾸미기 모자로 두지 않는다
- ● 망치 둘 (R22): 룬마스터는 마법 망치로 싸운다(전투 무기. 늘 보이는 표식은 룬). 기술자의 망치는 함정·도구·포탑 등을 만드는 제작용이고 전투에 쓰지 않는다. 기술자는 만든 장치로 싸운다
- ○ 마법 망치는 공격할 때만 손에 나타나고, 머리가 빛나서 기술자의 쇠망치와 다르게 보인다
- 그리는 규칙은 concept-art-brief §5.6

### 외형 꾸미기 (● 분류 R21)

- ● 외형은 클래스와 무관하게 플레이어가 꾸민다
- ● 분류. 신체: 피부색, 머리 모양, 머리색, 옷 색, 얼굴. 장비: 모자, 상의, 장갑, 하의, 신발, 망토
- ● 종족 전용 파츠: 그 종족만 고를 수 있고, 고르지 않아도 된다. 드워프답게 꾸밀 수도, 종족 요소를 뺀 모습으로 꾸밀 수도 있다. 엘프 = 뾰족 귀, 드워프 = 수염, 인간 = 전용 파츠 없음 (R22. 귀도 수염도 없는 얼굴이 곧 인간)
- ● 처음(슬라이스, §12)에는 분류만 정하고 바꿀 수 없다. 기본값만 쓴다 (리소스 통제)
- ○ 그래도 스프라이트는 처음부터 몸 + 파츠 + 표식 장비 레이어로 만든다. 나중에 바꾸면 모든 애니메이션을 다시 만들어야 한다 (concept-art-brief §5.6)
- ○ 모자는 장비 파츠다. 머리 모양과 겹치는 규칙(가리는 정도 3종, 종족 파츠는 모자 밖)은 concept-art-brief §5.6
- ● 장비 능력치와 외형 (R22): 모자·상의 등은 능력치가 있는 장비(룬마스터 제작)라 입은 장비가 외형이 된다. 외형 슬롯은 따로 두지 않고, 투구 숨기기 토글을 둔다 (모자를 숨기면 머리 모양이 보인다)

## 4. 컬렉션 시스템 (결정 + 제안)

결정된 뼈대:
- 월드마다 독립 (새 월드 = 새 컬렉션 → 리플레이 가치)
- 달성 단위: 자원, 생물, 업적 등
- 베네핏 범위: 특정 클래스 / 전체 클래스 / 월드
- 구역별 클래스 잠금: 희귀 생물 포획·사냥은 아처만
- 희귀 수집품에서 나오는 특정 재료 → 특정 장비 제작에 필수

제안:
- 클래스 베네핏 = 개인 성장 트랙. 월드 베네핏 = 공동 트랙 (제단 진행 조건의 일부)
- 모든 클래스에 전용 구역 하나씩 (§3 표). 클래스가 없으면 그 구역은 비어 있고, 그게 "그 클래스가 필요한 이유"
- 아처(희귀 생물 포획) → 약초사(추출·사육) 같은 클래스 간 체인을 컬렉션 안에 심는다
- 컬렉션 UI = 성서/코덱스. 채색 필사본처럼 (§10 성화 UI 레이어)
- 레퍼런스: 팰월드 팰덱, 그라운디드 분석기, 스타듀밸리 박물관

## 5. 월드 오염과 정화 (팔라딘 동사에서 파생, 제안)

팔라딘의 동사 "지속적으로 오염되는 월드를 정화"는 시스템 하나를 요구한다.
- 오염원: 이단의 제단, 타락한 둥지, 악마의 균열 같은 "원천"에서 오염이 타일 단위로 서서히 번진다
- 제단(코어)의 안전 반경은 오염을 밀어낸다. 반경 밖은 방치하면 잠식된다
- 팔라딘의 정화가 오염을 되돌리고, 원천을 토벌하면 확산이 멈춘다
- 이것이 생존 압박 후보다. 허기·갈증 대신 "땅이 잠식된다"는 영역형 압박 (돈스타브의 정신력, 인슈라우디드의 안개, 테라리아의 오염 확산)
- 혼자 개발 주의: 타일 월드에서 확산 시뮬레이션은 비용이 크다. 원천 몇 개 + 느린 틱 + 반경 규칙으로 단순하게. 슬라이스에서는 확산 없이 "정화할 고정 오염 구역"만

## 6. 적의 단계 = 티어 게이팅 (제안)

세계관의 적 진행이 그대로 보스 게이팅이 된다.
- 1단계 이단: 인간. 첫 지역의 적과 첫 보스 (이단의 지도자)
- 2단계 타락: 변이한 존재. 두 번째 지역과 보스
- 3단계 악마화: 악마에 잠식된 것들
- 4단계 악마: 최종 적
각 단계의 보스를 넘으면 다음 단계의 적과 자원과 컬렉션 구역이 열린다.

## 9. 설계 방향 (제안, 미확정)

### 9.1 클래스 원칙

- 클래스는 전투 역할 + 월드 동사 + 전용 컬렉션 구역, 세 겹으로 정의된다
- 9클래스 = 각자 고유 인물 (돈스타브 투게더 모델). 최대 인원 9인 확정
- 클래스 부재 대비: 3단 접근 규칙 (gameplay-design.md §3.0). 대체 수단 → 공용 수행 → 클래스 전용. 진행은 되지만 천장이 낮아진다. 전용 컬렉션 구역은 비어 있음
- 범위상 가장 무거웠던 기술자에서 대장장이를 룬마스터로 이관 (R10). 기술자는 §9.6 장치 하나로

### 9.2 두 트랙 성장

- 공동 트랙: 제단 진행. 보스 = 문. 팀 구성이 필요
- 개인 트랙: 전용 컬렉션 구역 + 클래스 동사. 혼자서도 돌아간다
- 연결: 컬렉션의 월드 베네핏과 희귀 재료가 공동 트랙으로 흐른다
- 파워 갭 제어: 개인 트랙의 티어 상한을 공동 트랙에 묶는 소프트 캡 (미결)

### 9.3 제단 (결정된 뼈대 + 제안)

- 결정: 코어 = 제단. 위치 자유, 이동 자유
- 제단을 세우는 행위 = 땅을 축성. 안전 반경(빛, 스폰 억제, 오염 저항)이 생기고 티어가 오르면 넓어진다
- 형태 (● R15 아트 기준, 북극성 v6): 낮고 넓은 정사각 석제단, 윗면에 등잔 9개(3×3)
- ○ 제안: 켜진 등잔 수 = 집단 기도 참여 인원 또는 접속한 클래스 수 (메커닉 후보. 북극성에서는 9개 모두 켜 둠)
- 성직자의 집단 기도는 제단에서
- 팔라딘의 정화가 반경 밖의 땅을 되찾는다
- 제단 진행 조건: 컬렉션 월드 베네핏 + 클래스별 기여물 (미결)
- 이동이 자유로우므로 "제단을 옮겨 새 지역으로 전진"이 팀 이벤트가 된다

### 9.4 집단 기도

- 장소: 제단 또는 성직자가 세운 임시 제단. 전투 중 불가 → "출정 전 의식"의 리듬
- 절차: 성직자가 기도 종류 선택 → 참여자가 원 안에 서서 동시에 채널링 (15~30초) → 방해받으면 중단 → 성공 시 참여자 전원 버프
- 참여 인원이 많을수록 강해진다 → 단체 행동을 강제하되 강요는 하지 않는다
- 신앙 자원: 성물·성지 발견, 봉헌으로 축적, 기도에 소모 → 성직자의 개인 트랙
- 기도 종류: 가호(방어) / 열정(공격) / 인도(탐험·시야) 등. 성직자가 고른다
- 혼자일 때: 자기 기도로 소형 버프
- 짧고, 의미 있고, 건너뛰면 손해가 있어야 한다

### 9.5 마법사 × 광부 원소-지형 상호작용

- 얼리기: 물·용암 표면을 얼려 건너감. 얼린 표면 아래로 광부가 접근
- 굳히기: 용암 → 흑요석. 광부만 캘 수 있는 희귀 재료
- 태우기: 덤불·독이끼 제거로 경로 확보. 재는 부산물
- 자화·감응: 일정 범위 광맥 하이라이트
- 폭발 vs 정밀: 마법 폭발은 넓지만 자원 손실, 광부는 정밀
- 보스전 콤보: 마법사가 바닥을 얼리면 광부가 얼음 기둥·벽을 세워 보스 동선 차단
- 순환: 광부의 원소 결정 → 마법사 인챈트 재료 → 룬마스터가 만든 룬 슬롯 곡괭이에 인챈트 → 더 깊이

### 9.6 기술자 = 장치

짓기·이동·운반·함정을 "장치" 시스템 하나로 묶는다. 무기·방어구 제작은 룬마스터(§3).
- 짓기: 다리, 발판, 방어벽 / 이동·운반: 레일·카트, 귀환 비콘, 보급 상자 / 전투: 지뢰, 덫, 포탑

### 9.7 약초사 = 농사 (○ 제안, R23)

약초사는 슬라이스의 다섯 번째 클래스다(§12). 월드 동사의 줄기를 Tiny Farm RPG의 농사 구조에서 가져온다(구조만 참고하고 이미지는 쓰지 않는다, concept-art-brief §5.6).
- 줄기: 씨앗주머니(표식, §3) → 제단 빛 안에 밭을 일군다 → 심기 → 물주기 → 성장 단계 → 수확 → 약제 조제 → 약제 투척(정체성 스킬, gameplay-design §2.2)·지원 약제(§3 소모형)
- 작물은 Tiny Farm처럼 씨앗 → 성장 4~6단계 → 수확물로 그린다. 조제는 연금술대 자리의 조제대에서 한다 (concept-art-brief §5.6 Tiny Farm 정식판 구조)
- 밭은 제단 빛(안전 반경) 안에서만 일군다. 빛 안의 아기자기한 삶이 가장 잘 보이는 자리다(§10 톤 이원화). 제단을 옮기면 밭은 남고 빛 밖이 된다
- 오염과의 대비: 빛 밖에 남은 밭이나 오염에 닿은 작물은 시든다. 팔라딘이 정화하면 되살아난다. 생활과 위협이 밭 한 칸에서 만난다(슬라이스는 확산이 없으므로 고정 오염 구역 옆 밭으로 시험한다)
- 공용과 전용(gameplay-design §3.0): 누구나 일반 작물을 심고 거둔다(느림, 일반 등급). 약초사는 성장이 빠르고 상급 등급을 거두며 약초·독초 씨앗은 약초사만 심는다. 슬라이스는 작물이 모두 약초라 §12 ●(R37)대로 회복·버프 약초는 누구나 일반 등급으로 심고, 독초 씨앗만 약초사가 심는다
- 채집: 야생 약초·균류는 지상과 던전에 자란다. 약초사가 캐면 상급(gameplay-design §3.4). 독초·균류는 타락한 식물 적(버섯·독꽃 같은 것, §6의 2단계 타락)에게서도 얻는다
- 동물(2차): 아처가 포획한 생물을 약초사가 기르고 추출한다(§4 체인). Tiny Farm의 가축·쓰다듬기 동작을 참고한다
- 슬라이스 범위는 §12

## 10. 아트 방향 (● 도트·A안 기준 확정 R6, ● 정렬형 탑다운 R15, ● 도트 구조 Tiny Farm RPG R18, ● 톤 이원화 R19, ● 클래스 표식 장비 R21 / 세부 사양은 ○ 제안)

조건: 탑다운, 타일 기반 파괴 지형, 화면에 최대 9명, 혼자 + AI. 톤: 어두운 세계, 종교적 신념, 생존.

### 결정: 톤 이원화 (R19)

- ● 캐릭터, 월드 안의 상호작용, 생활 동사(채굴·건설·제작·기도 등), 꾸미기 요소는 아기자기하게 한다
- ● 외부 위협(이단·타락 적, 오염 지대, 던전, 악마)은 기존 컨셉의 음울한 색으로 한다 (북극성 v6, 아래 팔레트의 타락·악마)
- 세계는 여전히 어둡고 위협적이지만, 사람들이 사는 곳은 따뜻하다. 그 대비가 톤이다
- ○ 해석: 제단의 빛(안전 반경) 안이 아기자기한 삶, 빛 밖이 음울한 위협. 빛 = 신앙 = 안전과 같은 경계를 쓴다
- 꾸미기는 여기서 건설물·소품의 외형과 캐릭터 외형 꾸미기(§3, R21)를 말한다. 건설물 꾸미기를 별도 시스템으로 만들지는 정하지 않았다 (슬라이스 범위 §12)

### 결정: 도트 (픽셀, R6)

이유: 타일 월드는 태생이 픽셀이다. 9명이 한 화면에 있을 때 가독성이 좋다. 애니메이션 비용이 프레임 수로 묶여 있어 혼자서도 감당된다. AI 도구(PixelLab 등)가 캐릭터·애니메이션·타일셋을 일관되게 뽑아준다. 손그림 2D는 분위기가 가장 좋지만 9클래스 × 애니메이션을 혼자 프레임으로 그리는 것이 최대 리스크.

### 성화 UI 레이어 (어느 후보와도 결합)

스프라이트는 픽셀이어도 UI는 다른 언어를 쓴다. 스테인드글라스, 금박, 채색 필사본(펜티먼트). 컬렉션 = 코덱스, 기도 화면 = 제단화, 스킬 아이콘 = 성화. 게임 화면과 UI의 대비가 "세속과 성스러움"을 표현한다.

### 팔레트 (제안)

- 생활 (R19): 따뜻하고 밝은 흙·나무·풀·천. 채도는 Tiny Farm에 가깝게, 그림자는 따뜻한 갈흑. 캐릭터·생활 공간·꾸미기. 세부 색은 3단계 시험으로 정한다
- 기반: 재, 돌, 가죽, 흙 — 채도 낮은 갈회색. 생활 공간 밖의 야외와 던전 (R19 전에는 "화면의 80%")
- 신앙: 촛불, 금, 상아 — 제단, 기도, 성직자·팔라딘의 강조색. 빛이 곧 이 색. 생활과 위협 양쪽에 쓴다
- 타락: 멍든 보라, 병든 녹, 뼈 — 오염 타일, 이단·타락 적
- 악마: 응고된 피, 주홍, 불 — 후반 적. 이전 단계와 대비되게
- 테라리아의 보라 오염과 겹치지 않게 타락 색의 비율과 질감으로 차별화

### 픽셀 사양 (A 기준 제안)

- ● 투영: 정렬형 탑다운 3/4. 정사각 타일이 화면과 나란하다. 아이소메트릭·회전 격자가 아니다 (R15, 북극성 v6)
- ● 도트 구조는 Tiny Farm RPG(itch.io)와 같다: 타일 16px, 캐릭터 프레임 32×32에 2등신 키 약 30px(프레임을 거의 채움, R20. Tiny Farm의 약 20px보다 큼), 1px 어두운 외곽선, 재질마다 2~3단 명암, 바닥은 위에서·인물은 정면에 가깝게. 북극성 v6는 분위기·질감·팔레트 기준이다 (R18, concept-art-brief §5.6). A안의 "32px"는 프레임 크기다. 방향은 아래·위·옆을 그리고 반대쪽 옆은 좌우 반전 (R19)
- 2D 라이트 + 노멀맵. 제단의 빛이 안전 반경을 그린다
- 팔레트 48색 내외로 제한. 북극성 v6 기준으로 그림자는 따뜻한 갈흑이고 청색·남색이 없다. 오염의 보라는 가는 맥에만 쓴다
- 클래스 판별: 표식 장비(● R21, §3) + 발밑 표식의 클래스 색. 두 겹으로 9명 구분 (체형은 모두 같고, 모자·옷·옷 색은 꾸미기라 클래스를 싣지 않는다)

## 12. 수직 슬라이스 범위 (제안)

- ● 클래스 5개 (R23. 약초사 추가): 팔라딘(보호·정화), 광부(파기), 아처(화력 + 컬렉션 검증), 성직자(치료 + 기도 검증), 약초사(키우기 + 약제 검증). 나머지 4개(마법사·시프·기술자·룬마스터)는 2차
- ○ 약초사 범위: 밭과 작물 3종(성장 단계 포함, 아래 ●), 약제 2~3종(회복 1, 버프 1, 상태이상 1), 약제 투척. 오염에 시드는 작물을 팔라딘이 되살린다 (§9.7)
  - ● 작물은 3종: 회복 약초, 버프 약초, 독초 (R28, 사람이 정함. 회복·버프·상태이상 약제에 하나씩 맞춘다. 그림은 concept-art-brief §5.7)
  - ● 누가 무엇을 심는가 (R37, 사람이 정함): 회복·버프 약초는 누구나 일반 등급으로 심고 거둔다. 독초 씨앗은 약초사만 심는다(gameplay-design §3.0 표의 "상태이상 약제는 약초사"와 맞음). 그래서 §11의 공용 농사와 gameplay-design §3.0 표(● R11)의 "누구나 농사"가 슬라이스에서 시험된다. 작물은 위 ●대로 3종이고, 약초사의 빠른 성장·상급 등급은 §9.7(○) 그대로다
- ○ 4인 시험이면 5클래스 중 하나는 늘 빈다. 빈 클래스를 대체 수단으로 메우는 3단 접근 규칙(gameplay-design §3.0)이 그대로 시험된다
- 제단 배치 + 업그레이드 1단계 + 빛 반경
- 지상 시작 구역 + 첫 던전 1개 (= 첫 오염 원천)
- 보스 1개 (이단의 지도자), 광부의 지형 상호작용 요소 1개 포함
  - ? 광부의 지형 상호작용 요소가 무엇인지 (R29. 그림 쪽 안: 광부가 부수면 잔해가 떨어지는 금 간 받침 기둥, 상태 4단계. concept-art-brief §5.7)
- ● 나무(목재 원천)를 넣는다, 가장 작게 (R37, 사람이 정함): 나무 1종을 누구나 벤다(공용 벌목). 건설·작업대가 나무를 쓰기 때문이다. ○ 벌목 도구는 도끼(concept-art-brief §5.6의 도끼·낫 동작). 나무 그림과 벌목 동작은 아직 없다(concept-art-brief §5.7, 생성은 비용 승인 뒤)
- 작업대 체인 2~3단계
- 컬렉션은 아처 구역 1개, 항목 5~10개
- 고정 오염 구역 2~3곳, 팔라딘이 정화
- 2인 접속 → 4인. 9인은 구조만 대비
- ● 캐릭터 외형: 꾸미기 분류(§3)만 정하고 바꿀 수 없다. 기본값만 쓰고, 클래스는 표식 장비로 구분한다 (R21). ○ 기본 외형 한 벌을 모든 클래스가 같이 쓴다 (표식 장비만으로 클래스가 읽히는지가 그대로 시험이 된다)
- 판정 기준: 루프 한 바퀴가 재미있는가. 컬렉션이 혼자 놀 이유가 되는가. 기도가 의식처럼 느껴지는가. 제단의 빛이 "안전"으로 읽히는가. 표식 장비만으로 클래스가 구분되는가. 빛 안의 밭이 지킬 이유가 되는가 (R23)

## 13. 도구 / 개발 방향 (초안)

확정된 조건: 2D 탑다운, 타일 기반 파괴 지형, 9인 온라인, 혼자 + AI. 아트는 도트로 확정 (R6).

- ● 엔진: Godot 4.7 (R30, 사람이 정함). 공식 4.7.2-stable 빌드로 버전을 고정하고 저장소 밖에 둔다(README 시작하기). 타입을 붙인 GDScript만 쓰고 C#은 쓰지 않는다. 에이전트는 헤드리스 CLI로 임포트·테스트·내보내기를 한다
