- ○ PC 우선. 게임패드는 2차
- ○ 키 배치 (초안)

## 2. 전투

### 2.1 기본 형태
- ● 실시간 액션
- ● 에임형 (마우스 방향 스킬샷). V 라이징, 해머워치 (R12 결정)
- ○ 힐과 버프만 "가까운 아군 자동 대상". 성직자가 9명 중 하나를 클릭해서 힐하는 건 도트 탑다운에서 괴롭다

### 2.2 스킬 킷 구조 (? 선택 중)

선택지 (R12):

| | 방식 | 참고 | 정체성 | 빌드 다양성 | 루트의 의미 | 혼자 개발 범위 |
|---|---|---|---|---|---|---|
| A | 고정 킷. 기본 + 스킬 3 + 시그니처 | 하데스, V 라이징 | 가장 강함 | 낮음 | 스탯 위주 | 9×4 = 36 |
| B | 무기 기반. 스킬은 장착 무기가 정함. 클래스는 무기군 + 패시브 + 시그니처 | 테라리아, 코어키퍼 | 무기가 겹치면 약함 | 중간 | 가장 큼 | 무기 종류만큼 애니메이션 |

○ 추천: A로 시작해 B·C를 섞는 하이브리드. 슬롯 4개의 역할을 나눈다.
1. 정체성 스킬 — 고정. 이 클래스를 이 클래스로 만드는 하나 (팔라딘 도발, 룬마스터 결계, 약초사 약제 투척)
2. 무기 스킬 — 장착 무기가 정함 (B). 클래스당 무기군 2개, 무기군마다 스킬 1
3. 선택 스킬 — 해금 풀 3~4개 중 1 (C 축소판). 해금 = 컬렉션 베네핏 → 개인 트랙과 연결
4. 시그니처 — 고정. 클래스 자원 소모 (D의 요소)

범위: 9 × (고정 2 + 선택 4) + 무기군 18 = 72. 슬라이스: 4클래스 × 고정 2 + 무기군 4 = 12.

클래스 자원 (○, 어느 방식이든 유지):
  - 팔라딘: 신념 (피해를 받거나 막을수록 쌓임)
  - 성직자: 신앙 (기도·성물·봉헌으로 쌓임)
  - 시프: 연계 (연속 타격으로 쌓임, 피격 시 리셋 = 하이리스크)
  - 마법사: 마력 (시간 회복)
  - 아처: 집중 (정지 상태에서 쌓임 = 로우리스크의 대가)
  - 광부: 지구력 (채굴로 쌓임 → 전투에서 지형 스킬로 씀)
  - 약초사: 재료 (채집한 약초·독을 소모)
  - 기술자: 부품 (제작·수리로 쌓임 → 장치 설치)
  - 룬마스터: 룬 (모루에서 장전, 전투 중 망치 타격으로 소량 회복 → 출정 전 준비의 순간)

### 2.3 어그로 (○)
- 적은 "위협" 수치가 가장 높은 대상을 공격한다
- 위협은 피해량에 비례. 팔라딘 스킬은 위협을 곱하거나 강제로 끌어온다 (도발)
- 힐은 위협을 넓게 조금씩 올린다 (성직자가 어그로 끌리는 MMO 문법)
- 이게 없으면 9인 협동에서 탱커 클래스가 성립하지 않는다

### 2.4 피해와 방어 (○)
- HP + 방어력(피해 감소). 스태미나(대시·방패)
- 피해 속성은 셋만: 물리 / 신성 / 부정
  - 신성: 성직자·팔라딘·인챈트. 타락·악마에게 추가 피해
  - 부정: 이단·타락한 적. 맞으면 HP 외에 오염 게이지가 오른다 (생존 압박 후보와 연결)
- 상태이상: 약초사 담당. 중독·둔화·취약·출혈 4종으로 시작
- 군중 제어: 팔라딘(도발·기절·밀치기)과 룬마스터(룬 봉인 속박·침묵, 룬 결계 차단) 둘이 담당

### 2.5 대시와 리스크 (○)
- 모두 대시 1회 (스태미나). 시프는 대시 후 다음 공격 강화 + 대시 2회 = 하이리스크 하이리턴을 조작으로 구현
- 아처는 정지 시 집중이 쌓이고 이동하면 빠진다 = 로우리스크 로우리턴을 조작으로 구현

### 2.6 사망 (● R12 결정: 내구도 손상 + 일부 아이템 드롭)

- 다운 상태 → 아군이 F 홀드로 소생 (성직자는 즉시, 다른 클래스는 5초) → 30초 넘기면 사망
- 사망 시: 장착 장비는 유지하되 내구도 손상 (기술자 수리 = 기술자 일감). 인벤토리의 재료·소모품 중 일부가 죽은 자리에 가방으로 떨어지고 되찾을 수 있다 (구출 플레이)
- ○ "일부"의 세부: 장착·퀘스트 아이템 제외, 스택마다 절반 또는 무작위 3종. 슬라이스에서 정한다
- 부활 지점: 제단

## 3. 월드 상호작용

### 3.0 3단 접근 규칙 (● R11 결정)

모든 클래스 동사는 세 단계로 열린다. 어떤 클래스가 비어도 진행은 되지만 효율과 생산성의 천장이 낮아진다. 전체 콘텐츠를 다 돌리도록 유도하는 장치.

1. 대체 수단: 상점 또는 기본 수단으로 누구나 얻는다. 성능 상한이 있고 지속 공급이 안 된다
2. 공용 수행: 그 동사를 누구나 할 수 있다. 효율이 낮고 일부 재료·등급이 잠긴다
3. 클래스 전용: 최고 효율, 최상위 결과, 전용 재료, 전용 컬렉션 구역. 천장은 여기서만 열린다

| 클래스 동사 | 대체 수단 (상점·기본) | 공용 수행 (누구나, 낮은 효율) | 클래스 전용 (천장) |
|---|---|---|---|
| 약초사 — 약제·농사 | 상점 포션. 성능 상한, 지속 공급 불가 | 누구나 농사·채집. 성장 느리고 일반 등급 약초만 | 상급·최상급 약제, 상태이상 약제, 희귀 약초 재배, 생물 추출 |
| 아처 — 사냥·포획 | 상점의 일반 가죽·고기 | 누구나 사냥. 가죽 손상으로 수율 낮음. 포획 불가 | 온전한 가죽, 희귀 생물 포획, 희귀 재료 → 특정 장비 |
| 광부 — 채굴 | 상점의 저급 광석 소량 | 누구나 채굴. 느리고 1×1, 경도 상한 | 3×3 고속, 상위 경도, 보스전 지형 상호작용, 심층 광물 |
| 룬마스터 — 제작·각인 | 상점 1티어 장비 | 누구나 모루에서 1~2티어 제작. 룬 슬롯 없음 | 룬 슬롯 장비, 벽·문 룬 강화, 결계, 잃어버린 룬 해금 |
| 마법사 — 인챈트·원소 | 상점의 일회용 속성 부적 | 누구나 마법진에서 기본 인챈트. 지속 짧고 등급 낮음 | 상위 인챈트, 원소로 지형 변화, 마력 이상 지대 |
| 기술자 — 장치 | 상점의 기본 키트 (횃불, 발판) | 누구나 벽·바닥·문·작업대 건설 | 레일·카트·비콘·포탑·함정, 장치 수리, 고대 기계 |
| 성직자 — 기도·치료 | 상점 치유 포션 (소량) | 누구나 제단에서 짧은 묵상 → 소형 버프. 누구나 소생 (느림) | 집단 기도, 즉시 소생, 신앙 자원, 성지 |
| 팔라딘 — 정화·토벌 | 상점의 성수 (소량 정화, 비쌈) | 누구나 성수로 타일 몇 개 정화. 오염 원천은 누구나 전투로 파괴 가능 | 광역 정화 채널링, 원천 봉인, 반경 확장, 토벌 기록 |
| 시프 — 유적·함정·희귀품 | 상점 열쇠 (비싸고 일부 상자만) | 누구나 함정·상자를 부수고 지나감. 보상 손상·일부 소실 | 함정 해제로 보상 온전, 잠금 해제, 은닉처 감지, 유물 |

전투 역할도 같은 규칙: 팔라딘 부재 시 광부·시프가 어그로를 잡되 약하게, 성직자 부재 시 약초사 약제로 버티되 소생이 느림.

따라오는 시스템: 제단 곁 상인 NPC (순례 상인). 수직 슬라이스에서는 4클래스뿐이라 나머지 5개 동사의 대체 수단으로 필수. 재화는 미결 (화폐 / 자원 교환·봉헌).

### 3.1 타일 월드와 월드 구조

- 16px 타일. 레이어: 바닥 / 벽(파괴 가능) / 광맥 / 식생 / 오염 / 설치물
- 벽 타일에 경도 등급. 곡괭이 등급이 경도 이상이어야 파괴 (테라리아). 상위 광석은 상위 곡괭이 → 광부 개인 트랙의 축
- ● 지상 + 지하 (R12 결정. 구조는 틀을 잡아가며 조정 가능)

○ 월드 구조 제안 (R12):
- 지상 = 사는 층. 제단, 농사, 사냥, 건설, 상인. 경계 있는 하나의 연속 맵, 절차 생성. AAA식 오픈월드가 아니라 테라리아 월드를 탑다운으로 눕힌 것
- 던전 = 나가는 층. 별도 맵. 지상의 입구로 진입. 던전 하나 = 바이옴 하나 = 티어 하나 = 보스 하나. 채굴, 유적, 오염 원천, 보스가 여기
- 세션 리듬과 일치: 흩어진다 = 지상 / 모인다 = 제단 / 원정 = 던전
- 혼자 개발에 유리한 점: 던전을 하나씩 추가하는 모듈 콘텐츠. 타일 동기화가 던전 안 인원끼리만 일어나 9인 부담 감소. 파티 분할 가능 (일부는 던전, 일부는 지상). 혼자 접속한 날은 지상만
- 오염 흐름: 원천은 던전 안(이단의 제단). 입구를 통해 지상으로 번진다. 팔라딘이 지상을 정화하고 던전 원천을 봉인하면 멈춘다. 던전 하나 정리 = 지상 한 구역이 밝아진다
- 제단 이동: 다음 던전 입구 쪽으로 전진하는 팀 이벤트
- ? 지상의 빛 (결정 필요):
  - 낮밤 사이클: 밤에 위험, 제단의 빛이 밤의 안전. 테라리아, 돈스타브
  - 영원한 황혼: 세계가 이미 어둠에 잠식. 제단의 빛만 밝다. 인슈라우디드의 안개. "빛을 되찾는다"는 정화 서사와 일치, 던전 정리마다 지상이 밝아지는 것이 보임
  - ○ 추천: 황혼

### 3.2 채굴 (○)
- 마우스 방향의 인접 타일을 타격. 홀드하면 연속
- 누구나 가능하지만 느리다. 광부는 범위(3×3)와 속도가 압도적, 상위 경도 타일은 광부만
- 채굴 시 드롭은 인벤토리로 자동

### 3.3 건설 (○)
- 핫바에서 블록·구조물 선택 → 그리드 스냅 배치, 우클릭 철거
- 벽·바닥·문·작업대·조명은 공용. 다리·레일·비콘·포탑 같은 "장치"는 기술자만
- 제단 반경 안은 건설 비용 감소 또는 즉시 건설 (거점을 반경 안에 두게 유도)

### 3.4 채집·사냥·포획 (○)
- F로 식물·드롭 줍기
- 원칙 (●): 3단 접근 규칙 §3.0. 약초를 약초사가 캐면 상급 등급, 다른 클래스는 일반 등급. 생물을 아처가 잡으면 가죽이 온전, 다른 클래스는 손상
- 포획: 아처 전용 도구(올가미·덫). 희귀 생물의 HP를 일정 이하로 낮춘 뒤 포획 시도 → 컬렉션 등록 → 약초사에게 인계 가능

### 3.5 제작 (○)
- 작업대 근처에서 Tab. 레시피는 재료를 처음 획득했을 때 해금 (그라운디드 분석기 방식) → 컬렉션과 연결
- 작업대 체인: 기본 작업대 → 모루(대장간) → 성물 제작대 → (이후 티어)
- 무기·방어구: 1티어는 누구나 모루에서 제작 가능. 룬 슬롯이 있는 상위 장비는 룬마스터만 ("누구나 하지만 클래스는 결과가 다르다")
- 마법사 인챈트는 별도 작업대(마법진)에서, 룬 슬롯이 있는 장비에 원소 결정 소모. 순서: 룬마스터 제작 → 마법사 인챈트

### 3.6 기도 (○, game-concept 9.4 요약)
- 제단(또는 성직자가 세운 임시 제단) 반경에서 성직자가 기도 선택 → 참여자가 F 홀드 → 원형 UI에 참여자 수 표시 → 15~30초 → 버프
- 전투 중 불가. 방해받으면 중단

### 3.7 정화 (○)
- 팔라딘이 오염 타일 위에서 스킬 채널링 → 반경 N타일 정화. 오염 원천(이단의 제단·둥지)은 파괴해야 재오염이 멈춤
- 슬라이스: 확산 없음, 고정 오염 구역 2~3곳

## 4. 세션 흐름 (○)

한 세션 약 60분을 기준으로 한 리듬. 이 리듬이 "왜 모이는가"를 만든다.

1. 제단에서 출발. 공유 창고에서 보급
2. 흩어진다 (20분, 지상): 아처는 사냥하고, 약초사는 캐고, 기술자는 짓는다. 광부·시프는 얕은 던전을 돈다. 각자 개인 트랙
3. 돌아온다 (15분): 제작, 건설, 인챈트, 창고 정리. 컬렉션 등록
4. 모인다: 성직자의 기도. 이게 "출정" 신호
5. 원정 (20분, 던전): 다 같이 새 던전 또는 보스. 팔라딘 선두
6. 해금: 보스 처치 → 제단 티어 → 새 레시피·지역·컬렉션 구역
7. 다음 세션의 목표가 생긴다

혼자 접속한 날: 2~3번만 반복. 개인 트랙이 돌아가고 산출물이 창고에 쌓인다.

## 5. 협동 규칙 (○)

- ● 최대 9인. 호스트 월드. 드롭인·드롭아웃. 캐릭터는 개인, 월드는 공유 (테라리아식) — 계정당 캐릭터 수는 미결
- 파티 UI는 3×3 (세 종족 × 세 직분)
- 공유 창고: 제단 옆. 개인 인벤토리는 각자
- 부활 지점: 제단. 제단을 옮기면 부활 지점도 옮겨진다
- 핑(G): 위치·적·자원 표시. 채팅은 텍스트 + 정해진 문구
- 아이템 소유: 드롭은 주운 사람 것. 보스 드롭은 인원수만큼 분배
